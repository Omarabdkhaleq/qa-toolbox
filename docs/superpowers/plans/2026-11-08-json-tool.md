# JSON Tool Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace JSON Editor and JSON Compare with one **JSON** tool — two full editors side by side, in-place structural compare (text, tree, table) with auto-sort, a Changes drawer, a resizable/collapsible split — plus an app-wide floating command palette with OS-aware shortcuts, and a clear "comments aren't supported yet" message.

**Architecture:** `src/tools/json/` composes two `EditorPane`s (today's JSON Editor toolbar, extracted) around a `MiddleMenu`, with a `ChangesDrawer` below. Compare reuses `structuralDiff`; a pure `highlightsFor(changes)` turns changes into per-side path→kind maps that `JsonEditorView` renders as CodeMirror line decorations (text view) and `onClassName` classes (tree/table). Commands live in `src/core/commands/` (registry context, OS-neutral shortcuts, OS-aware labels); the shell renders the floating button and palette; tools register their commands. Old tools stay registered and green until the last task removes them.

**Tech Stack:** React 19, TypeScript ~6.0, Vite 8, vanilla-jsoneditor 3, CodeMirror 6, lossless-json, jsondiffpatch, json-source-map, jsonrepair, Vitest 5, Playwright 1.65.

**Spec:** [`docs/superpowers/specs/2026-11-08-json-tool-design.md`](../specs/2026-11-08-json-tool-design.md) (approved, revised after plan review). Project rules: [`CLAUDE.md`](../../../CLAUDE.md), [`intent.md`](../../../intent.md).

## Global Constraints

- One tool: sidebar entry **JSON**, route `/#/tools/json`, id `json`. Old routes are **not** redirected.
- Comments are **invalid**. A parse error at a `/` that starts `//` or `/*` has the message `Comments aren't supported yet. Click Repair to remove them.` (with that position). No other comment handling.
- Ticking Compare runs Sort keys on both editors (each with its own indentation); no "Ignore key order" option. The Compare checkbox is disabled while either side is empty or invalid (reasons `Paste JSON on both sides to compare` / `Fix the JSON errors to compare`); if a side becomes empty or invalid while on, Compare turns off and highlights clear. While on, an editor re-sorts once when it loses focus and on whole-document replacements, never while typing.
- Highlights: removed = red tint left; added = green tint right; **changed = yellow tint both sides** (light `rgba(255,193,7,.22)`, dark `rgba(255,183,77,.20)`, bar `--changed`: light `#b26a00`, dark `#ffb74d`); moved = `--moved` both sides; every highlight has a 3 px left bar. At most `10_000` changes highlighted (note `Highlighting the first 10,000 of N changes`); drawer list capped at 1,000.
- Split: starts 50; snap closed under 15 %; min open pane 240 px; double-click/Enter → 50; ←/→ ±5; Home → 0 (left closed), End → 100 (right closed). Side closed ⇒ Compare controls disabled. ≤ 720 px: stacked, handle hidden.
- Shortcuts (OS-neutral definitions, `mod` = ⌘ on macOS / Ctrl elsewhere): palette `mod+K`; next/previous change `Ctrl+Alt+↓` / `Ctrl+Alt+↑` on every OS (macOS label `⌃⌥↓`), active only while Compare is on. Labels: macOS symbols without separators (`⌘K`, `⌃⌥↓`); Windows/Linux words with `+` (`Ctrl+K`, `Ctrl+Alt+↓`). Our listener is window-level, capture phase, and calls `preventDefault()` + `stopPropagation()` on a match.
- Floating palette button: bottom-right, 16 px inset (24 px ≥ 1200 px wide), 44 × 44 px, inline-SVG icon + key chip; lifted above the Changes drawer when it is open.
- `core/diff/TextDiffView.tsx` (+ CSS) and `core/diff/focus.ts` are **kept** (reused by roadmap v1.1 text diff).
- Theme tokens only; text ≥ 4.5:1, non-text UI ≥ 3:1, light and dark; honor `prefers-reduced-motion`.
- Unchanged project rules (CLAUDE.md): no egress; CSP without `unsafe-eval`; only `src/core/json-view/` imports `vanilla-jsoneditor`; tools never import `app/`; relative imports; coverage ≥ 90 % on `src/core/**/*.ts` + `src/tools/*/logic.ts`; budgets entry ≤ 150 KB gzip (palette adds no dependency), route ≤ 600 KB gzip, 20 MB open < 3 s, 5 MB compare **incl. highlight paint** < 3 s.
- **Protected tests:** only the files pre-approved in spec §10, only to port them (meaning kept) or remove the three approved key-order cases; anything else needs a per-case yes. Old tools and their tests stay green until Task 11.
- Commits: Conventional Commits; message describes only the change — no `Co-Authored-By`, model or tool names.

## Review Focus

1. **⌘K / Ctrl+K pressed while typing in an editor** opens the palette and inserts nothing, and the browser search bar does not take focus — pinned in Task 9.
2. **Commented JSON** (`{"a":1 // c}`) shows the comment message at the right line/column, and `"http://x"` alone is valid — pinned in Task 2.
3. **Big integers through auto-sort** (`{"b":12345678901234567890,"a":1}`) keep every digit after ticking Compare — pinned in Task 7.
4. **A side with broken JSON** disables Compare (and turns it off if it was on); the broken text is never rewritten — pinned in Task 7.
5. **Typing while Compare is on** never re-sorts or moves the cursor; the editor re-sorts once on blur — pinned in Task 7.
